# 🏥 TenderAI Med — ИИ-аудит тендеров медицинского оборудования

> **B2B SaaS MVP:** Автономный ИИ-анализатор тендерной документации по 44-ФЗ и 223-ФЗ для поставщиков медицинского оборудования (УЗИ, МРТ, КТ, эндоскопы, расходные материалы).

---

## 🚀 Быстрый старт за 1 минуту

### 1. Установка зависимостей (один раз)
```bash
pip install -r requirements.txt
```

### 2. Настройка OpenAI API (по желанию)
Скопируйте образец `.env.example` в `.env`:
```bash
copy .env.example .env
```
Откройте `.env` и укажите ваш `OPENAI_API_KEY`.  
> 💡 **Квоты и модели:** Вы можете использовать любые модели из вашей квоты (`gpt-4.1`, `gpt-4o`, `gpt-4.1-mini`, `gpt-4o-mini`, `o3-mini`, `o4-mini`). Выбор модели также доступен прямо в интерфейсе!  
> 🧪 **Если ключа нет под рукой:** Приложение автоматически поддерживает **Демо-режим (Mock Mode)**, позволяя опробовать полный функционал на эталонном образце закупки УЗИ-аппарата без обращения к API.

### 3. Запуск приложения
Запустите файл `run.py` (или дважды кликните `start.bat` в Windows Explorer):
```bash
python run.py
```
Интерфейс откроется в вашем браузере по адресу: **http://localhost:8501**

## 🎯 Что делает сервис

1. **📦 Универсальная загрузка:**
   - Принимает официальные архивы ЕИС (`.zip`) или отдельные файлы (`.pdf`, `.docx`, `.txt`).
   - Автоматически классифицирует: Техническое задание, Проект контракта, Информационная карта.
2. **🚦 Интеллектуальный светофор:**
   - 🔴 **Критический стоп-фактор:** Выявлена заточка под чужой бренд, нереалистичный срок (<7 дней), кабальные пени.
   - 🟡 **С оговорками:** Требуется подача запроса на разъяснение положений.
   - 🟢 **Рекомендовано к участию:** Чистый типовой контракт без скрытых ловушек.
3. **⚖️ Юридический анти-краш (ПП РФ № 1042):**
   - Находит завышенные пени (например, незаконные 0.5% в день вместо 1/300 ключевой ставки ЦБ РФ).
4. **🩺 Медицинский комплаенс:**
   - Проверка требований к Регистрационному удостоверению (РУ) Росздравнадзора.
   - Контроль национального режима по **Постановлению Правительства РФ № 878** (ограничение допуска радиоэлектроники, правило «третий лишний»).
   - Сверка с позициями **КТРУ** Минфина России.
5. **📝 Автогенерация официальных запросов в ЕИС:**
   - Формирует юридически выверенные письма заказчику со ссылками на ч. 4 ст. 65 44-ФЗ и ст. 17 135-ФЗ «О защите конкуренции».
   - Кнопка копирования в один клик для отправки через торговую площадку.
6. **💾 Экспорт отчета:**
   - Скачивание структурированного экспертного заключения в формате Markdown.

## 🧪 Тестирование и верификация

Все тесты запускаются одной командой:
```bash
pytest tests/ -v
```

Тестовый набор включает:
- Проверку распаковки архивов и чтения документов разных форматов (`test_extractor.py`)
- Валидацию строгих Pydantic-схем ответов (`test_schemas.py`)
- Сквозную симуляцию полного аналитического пайплайна (`test_analyzer.py`)

## 📁 Структура проекта

```
Tender/
├── app/
│   ├── config.py             # Настройки и ключи (.env)
│   ├── models/
│   │   └── schemas.py        # Pydantic схемы отчетов и рисков
│   ├── services/
│   │   ├── extractor.py      # Распаковка ZIP, чтение PDF/DOCX

│   │   ├── prompts.py        # Специализированные мед-промпты 44-ФЗ
│   │   ├── llm_service.py    # OpenAI Structured Outputs + Mock
│   │   └── analyzer.py       # Главный оркестратор конвейера
│   └── utils/
│       └── export.py         # Экспорт отчета в Markdown
├── ui/
│   └── app.py                # Интерфейс Streamlit (Светофор + Дашборд)
├── sample_data/

├── tests/                    # Юнит- и интеграционные тесты
├── run.py                    # Запуск сервиса
├── start.bat                 # Запуск двойным кликом в Windows
└── requirements.txt          # Библиотеки
```
