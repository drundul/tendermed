# 🚀 Walkthrough: Создание MVP TenderAI Med

> **Проект:** TenderAI Med — ИИ-анализатор тендерной документации медицинского оборудования  
> **Статус:** Реализовано и полностью протестировано ✅  
> **Стек:** Python 3.13, Streamlit, Pydantic, PyMuPDF, python-docx, OpenAI Structured Outputs (gpt-4.1 / gpt-4o / gpt-4.1-mini)

---

## 1. Что было сделано

В соответствии с утвержденным планом создан законченный, готовый к запуску MVP-сервис:

### 📦 Архитектурные компоненты:
1. **Конфигурация и окружение (`app/config.py`, `.env.example`, `requirements.txt`):**
   - Гибкая настройка моделей OpenAI с учетом бесплатных ежедневных квот пользователя (`gpt-4.1`, `gpt-4o`, `gpt-4.1-mini`, `o3-mini`, `o4-mini`).
   - Автоматический fallback и встроенный Mock-режим.
2. **Строгая Pydantic-модель данных (`app/models/schemas.py`):**
   - `FullAnalysisReport`, `TrafficLightVerdict` (🟢/🟡/🔴), `RiskItem`, `MedComplianceAudit`, `TenderSummary`, `ClarificationRequest`.
   - Обеспечивает 100% стабильную структуру ответов от OpenAI через механизм `beta.chat.completions.parse`.
3. **Модуль извлечения и нормализации (`app/services/extractor.py`):**
   - Распаковка архивов ZIP с защитой от traversal-уязвимостей.
   - Чтение текстовых и табличных данных из `.docx`, `.pdf` (PyMuPDF) и `.txt`.
   - Детекция графических сканов.
4. **Эвристический классификатор документов (`app/services/classifier.py`):**
   - Автоматически разделяет входящие файлы по типам: Техническое задание, Проект контракта, Информационная карта, Обоснование НМЦК.
5. **Медицинский промпт-инжиниринг (`app/services/prompts.py`):**
   - Тонкая калибровка под специфику госзакупок РФ: Постановление Правительства РФ № 1042 (предельные пени), Постановление Правительства РФ № 878 (нацрежим радиоэлектроники), Регистрационные удостоверения (РУ Росздравнадзора), ст. 33 44-ФЗ (правила описания и поиск «заточек» под конкретного производителя).
6. **LLM-сервис и конвейер (`app/services/llm_service.py`, `app/services/analyzer.py`):**
   - Оркестрация сквозного пайплайна: файлы → нормализация → LLM → структурированный отчет.
7. **Интуитивный веб-интерфейс на Streamlit (`ui/app.py`):**
   - Большой цветной баннер Светофора (🟢/🟡/🔴).
   - Информационные метрики (НМЦК, срок, аванс, обеспечение).
   - 5 функциональных вкладок: Матрица рисков с цитатами, Мед-комплаенс (РУ и ПП 878), Спецификация оборудования, Генератор запросов в ЕИС в 1 клик, Экспорт отчета в Markdown.
8. **Утилиты запуска и экспорта (`run.py`, `start.bat`, `app/utils/export.py`):**
   - Запуск приложения в один клик.

## 3. Как запустить и опробовать

1. Перейдите в папку проекта:
   ```powershell
   cd "c:\Users\User\Documents\Antigravity work\Tender"
   ```
2. Запустите:
   ```powershell
   python run.py
   ```
   *(или дважды кликните по файлу `start.bat`)*
3. В браузере откроется `http://localhost:8501`.
4. Нажмите кнопку **«⚡ Загрузить эталон (УЗИ Resona 7)»**, чтобы мгновенно увидеть результат работы системы со светофором, матрицей рисков и готовым запросом заказчику в ЕИС!
